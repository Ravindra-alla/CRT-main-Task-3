## 🤖 AI Features

### **4 Machine Learning Models:**

1. **Diabetes Prediction**
   - Algorithm: Random Forest
   - Features: Age, BMI, glucose, BP, family history
   - Accuracy: ~85%

2. **Heart Disease Assessment**
   - Algorithm: Logistic Regression
   - Features: Age, cholesterol, BP, heart rate, chest pain
   - Accuracy: ~82%

3. **Kidney Disease Prediction**
   - Algorithm: Random Forest
   - Features: Age, creatinine, BUN, GFR, BP
   - Accuracy: ~83%

4. **Cancer Risk Evaluation**
   - Algorithm: Logistic Regression
   - Features: Age, smoking, tumor size, inflammation, BMI
   - Accuracy: ~80%
